# Plantillas de Premiere

Acá va la plantilla de la que se clona el `.prproj` de una carpeta
(`engine/prproj-carpeta.js`), con el nombre `Plantilla-30.prproj`. El
instalador copia a `Resources/plantillas` solo los `.prproj` de esta carpeta.

Cómo armarla está en el README, sección «El proyecto de Premiere de la
carpeta» → «La plantilla». Para revisarla e instalarla:

```bash
node tools/validar-plantilla.js ~/Desktop/Plantilla.prproj --instalar
```
